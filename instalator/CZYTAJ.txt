Amadeusz (LokalneAI) - asystent AI biura ODS
============================================

INSTALACJA (bez praw administratora)
Z paczki:
1. Rozpakuj paczke Amadeusz-<wersja>.zip w dowolnym miejscu.
2. Kliknij dwukrotnie instaluj.bat i poczekaj na "Gotowe".
Z repozytorium (git clone https://github.com/Optimal-Design-of-Structures/Amadeusz.git):
   instalator\instaluj.bat - sam zbuduje program (potrzebny .NET SDK 10).

Model moze liczyc:
- na tym komputerze: instaluj.bat bez parametrow. Instalator zainstaluje Ollame
  i pobierze model Bielik 11B v3 (polski, SpeakLeash; ok. 7 GB, potrzebne ok. 8 GB
  wolnego miejsca). Najlepiej karta graficzna z 8 GB pamieci lub wiecej.
- na serwerze w biurze: instaluj.bat -SerwerModelu http://<serwer>:11434
  (Ollama na tym komputerze nie jest wtedy potrzebna).

Inny model: instaluj.bat -Model <nazwa>, np. szybszy i mniejszy
  -Model SpeakLeash/bielik-minitron-7B-v3.0-instruct:Q4_K_M

URUCHOMIENIE
Menu Start albo skrot na pulpicie: Amadeusz. Okno ma trzy zakladki:
  Czat       - zwykla rozmowa z modelem.
  Code       - asystent, ktory wykonuje polecenia; profile:
    tekla    - polecenia w modelu Tekli (na probe: symulator),
    cde      - pytania o godziny, projekty i dokumenty w bazie CDE
               (widoczny, gdy w Menedzerze poswiadczen jest baza "cde"),
    pliki    - tworzenie folderow, kopiowanie, przenoszenie (bez kasowania),
    komputer - polecenia PowerShella, zapisywanie skryptow, uruchamianie
               programow, czytanie i szukanie plikow. Dziala tylko
               w "Dozwolonych folderach"; to, co tylko czyta, idzie od razu,
               a kazda zmiane zatwierdzasz w okienku.
  Z lewej panel rozmow: kazda rozmowa zapisuje sie sama i wraca po kliknieciu.
  Grupa = folder roboczy ("+ Nowa grupa (folder)..."): asystent pracuje w nim,
  a rozmowy zapisuje tylko w jego podfolderze .amadeusz. Bez grupy:
  Dokumenty\Amadeusz\.amadeusz. Profile mozna zaznaczyc kilka naraz.
  Ustawienia - model, modele w chmurze, Menedzer poswiadczen, udostepnianie mocy
               obliczeniowej w sieci biura, czat.

Przelacznik "Odblokuj dostep do internetu" (u gory okna): czat i profile
tekla, pliki, komputer moga szukac w internecie (DuckDuckGo) i czytac strony.
Profil cde nigdy nie ma internetu. Adresy sieci biura sa dla modelu zablokowane.

Modele w chmurze (Claude, GPT, Gemini): Ustawienia -> Modele w chmurze (test), wlasny
klucz API. Zapytania do chmury sa platne. Profil cde: tylko modele lokalne i Claude.

HASLA I KLUCZE
Adresy, loginy i hasla baz, FTP i SMB sa w Menedzerze poswiadczen Windows
(Ustawienia -> Menedzer poswiadczen w programie; wpisy "Amadeusz:..."), klucze API
w %APPDATA%\LokalneAI\klucze.json - zaszyfrowane tylko dla Twojego konta Windows
na tym komputerze. Nie wpisuj ich do plikow w repozytorium.

DOKUMENTACJA DLA ASYSTENTA
Przycisk "Zrodla wiedzy..." w zakladce Code: wklej adres repozytorium (jak do
git clone) i wzorce plikow, np. README.md; docs/**/*.md. Pliki pobieraja sie od razu
i potem same co 6 godzin (potrzebny git i dostep do repozytorium).
Wlasne notatki (.md, .txt) mozna wrzucic do folderu profilu: profile\<nazwa>\wiedza\.

AKTUALIZACJA
Nowa paczka (albo git pull w repozytorium): instaluj.bat jeszcze raz. Ustawienia,
historia, hasla, klucze, zrodla wiedzy i wlasne notatki w folderach wiedza zostaja.
Skroty "LokalneAI" ze starszych wersji zamieniaja sie na "Amadeusz".

ODINSTALOWANIE
Ustawienia -> Aplikacje -> Amadeusz (LokalneAI). Ollama i modele zostaja
(odinstalowuje sie je osobno).

Gdzie co jest:
  program:        %LOCALAPPDATA%\Programs\LokalneAI
  ustawienia:     %APPDATA%\LokalneAI\ustawienia.json
  hasla i klucze: %APPDATA%\LokalneAI\klucze.json (zaszyfrowane)
  historia:       %LOCALAPPDATA%\LokalneAI\historia.jsonl
