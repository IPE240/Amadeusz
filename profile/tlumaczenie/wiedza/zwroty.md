# Mail: powitanie, zakończenie, w załączeniu, proszę o uwagi, pozdrawiam, z poważaniem

- „Dzień dobry,” → „Dear Mr Kowalski,” / „Dear Ms Nowak,” / „Dear Sir or Madam,” (gdy nie znasz nazwiska) / „Dear all,” (do grupy).
- „W załączeniu przesyłam…” → „Please find attached…” (np. „Please find attached the R02 report and the steel schedule.”).
- „Proszę o uwagi do piątku.” → „We would be grateful for your comments by Friday.” / „Please send your comments by Friday.”
- „Proszę o potwierdzenie…” → „Please confirm…” / „Kindly confirm…”.
- „Jeżeli nie będzie zastrzeżeń…” → „If there are no objections…” / „Unless we hear otherwise…”.
- „Pozdrawiam” → „Kind regards,” (neutralnie) / „Best regards,”.
- „Z poważaniem” → „Yours sincerely,” (znasz nazwisko) / „Yours faithfully,” (Dear Sir or Madam).
- „W razie pytań pozostaję do dyspozycji.” → „Should you have any questions, please do not hesitate to contact me.”
- „Przepraszam za zwłokę.” → „Apologies for the delay.”
- „Dziękuję za przesłane uwagi.” → „Thank you for your comments.”

# Pismo przewodnie, przekazanie rysunków, transmittal

- „Przekazujemy rysunki rewizji R02 konstrukcji stalowej hali.” → „We hereby submit the revision R02 drawings of the steel structure of the hall.”
- „Rysunki zastępują rewizję R01.” → „These drawings supersede revision R01.”
- „Wykaz przekazanych dokumentów w załączeniu.” → „A list of the transmitted documents is attached.”
- „Do wykonania” / „do informacji” / „do zatwierdzenia” → „for construction” / „for information” / „for approval”.
- „Rysunki warsztatowe przekażemy po zatwierdzeniu projektu wykonawczego.” → „Shop drawings will be issued after approval of the detailed design.”

# Notatka ze spotkania: obecni, ustalenia, do zrobienia, następne spotkanie

- „Notatka ze spotkania 2026-11-17” → „Minutes of meeting, 2026-11-17”.
- „Obecni:” → „Present:”; „Nieobecni:” → „Apologies:”.
- „Ustalenia:” → „Agreed:” / „Decisions:”; „Do zrobienia:” → „Actions:” (z osobą odpowiedzialną: „Action: ODS”).
- „Termin oddania projektu wykonawczego 30.11.” → „Detailed design to be submitted by 30 November.”
- „Kotwy do uzgodnienia z wykonawcą.” → „Anchor bolts to be agreed with the contractor.”
- „Następne spotkanie 24.11.” → „Next meeting: 24 November.”
- „Brak decyzji o…” → „No decision on… (pending)”.

# Uwagi do rewizji, opis zmian w tabelce rysunkowej

- „Rewizja R02 uwzględnia uwagi inwestora z 2026-11-10.” → „Revision R02 incorporates the client's comments of 2026-11-10.”
- „Zmieniono profil słupów z HEB300 na HEB320.” → „Column section changed from HEB300 to HEB320.”
- „Dodano stężenia połaciowe w osiach 3–4.” → „Roof bracing added in gridlines 3–4.”
- „Poprawiono zestawienie stali.” → „Steel schedule corrected.”
- „Bez zmian” → „No change”; „Wydanie pierwsze” → „First issue”.
- oś 3, osie A–D → gridline 3, gridlines A–D.

# Tytuły rysunków: rzut, przekrój, widok, szczegół, zestawienie

- „Rzut konstrukcji dachu” → „Roof structure plan”; „Rzut fundamentów” → „Foundation plan”; „Rzut stropu nad parterem” → „First floor slab plan” (BrE: parter = ground floor).
- „Przekrój A-A” → „Section A-A”; „Widok ściany w osi A” → „Elevation on gridline A”.
- „Szczegół podstawy słupa” → „Column base detail”; „Szczegół połączenia belki ze słupem” → „Beam-to-column connection detail”.
- „Zestawienie stali — rewizja R02” → „Steel schedule — revision R02”.
- „Schemat stężeń” → „Bracing layout”; „Schemat montażowy” → „Erection drawing (general arrangement)”.
