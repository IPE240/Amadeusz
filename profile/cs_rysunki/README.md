# Umiejętność `cs_rysunki`: rysunki w CS-check

Część zestawu umiejętności z repozytorium CS (podział i decyzje: `profile\cs_program\README.md`). Zakres: Układy (rysunki
montażowe płaszczyzn, szkice piórem, wykresy na osiach), arkusze zespołów, rysunki części, pliki NC DSTV, nesting oraz reguły
z wykładów, co konstruktor i montażysta czytają z arkusza.

## Pliki
| Plik | Co to |
|---|---|
| `profil.json` | profil wiedzy, bez `chmura`, bez internetu |
| `system.md` | rola i 7 zasad, w tym trzy rodzaje rysunków i prototypowy status NC |
| `karta.md` | ściąga: Układy i konwencja plastra, reguły UL z bilansem, zespoły i części, NC, nesting, mapa „pytanie → plik” |
| `przyklady.jsonl` | 10 przykładów (9 wyszukiwań, 1 odmowa z instrukcją) |
| `testy.jsonl` | 6 testów CR01–CR06 |
| `zrodla.json` | 15 wzorców: help uklady_*, wykłady o układach i rysunkach warsztatowych, plan układów, raport rozpoznania, pitfalls rysunki_warsztatowe_nc, README plane_view, assembly_view, part_view, nc_dstv, nesting, drawing_* |
| `wiedza/rysunki_cs.md` | 9 sekcji streszczenia w gicie |

## Uwagi
- `plane_view/README.md` (296 KB) i `assembly_view/README.md` (63 KB) są obszerne; sekcje powyżej 1500 znaków są dzielone przez wyszukiwarkę.
- Słownik szkiców i osi użytkownika (`glossary/osie_uklady.md` §22) jest w `cs_konstrukcja` (plik wspólny z §21 osie i poziomy).
