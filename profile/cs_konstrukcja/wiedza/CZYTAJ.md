# Wiedza umiejętności „cs_konstrukcja”

Ten plik jest dla ludzi: model go nie widzi.

- `klasyfikacja_cs.md`: streszczenie w gicie (warstwy klasyfikacji, role, typy zespołów, lider, osie i poziomy, płaszczyzny,
  obiekty i dylatacje, interpretacja).
- `zrodla\CS-cheak_structures\`: słownik domeny (`handbook/glossary.md` + pliki tematyczne), `interpretacja.md`, README modułów
  cs1–cs4, assembly*, axes_levels, podzial_obiektow i wykłady użytkownika. Poza gitem; pobiera „Aktualizuj” w Ustawieniach →
  Umiejętności.

Słownik jest jedynym źródłem prawdy wartości enum w CS (`handbook/glossary.md` i `glossary/*.md`); pisownia wartości
(`ryglowka`, `stezenie_polaciowe`) jest święta. Podział repozytorium CS na umiejętności: `profile\cs_program\README.md`.
