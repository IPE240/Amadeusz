# Umiejętność `cs_konstrukcja`: rozumienie konstrukcji w CS-check

Część zestawu umiejętności z repozytorium CS (podział i decyzje: `profile\cs_program\README.md`). Zakres: klasyfikacja
elementów (`klasa_p1..p4`), rola pręta w zespole i typ zespołu, zespoły i lider, podobieństwo i wzorce, osie i poziomy,
płaszczyzny i połacie, obiekty i segmenty dylatacyjne, interpretacja wyników.

## Pliki
| Plik | Co to |
|---|---|
| `profil.json` | profil wiedzy, bez `chmura`, bez internetu |
| `system.md` | rola i 7 zasad, w tym rozróżnienie trzech „obiektów” i święta pisownia wartości słownika |
| `karta.md` | ściąga: cztery warstwy klasyfikacji, role, typy zespołów, lider, osie/poziomy/płaszczyzny/obiekty, mapa „pytanie → plik” |
| `przyklady.jsonl` | 10 przykładów (9 wyszukiwań, 1 odmowa zmiany danych) |
| `testy.jsonl` | 6 testów CK01–CK06 |
| `zrodla.json` | 23 wzorce: indeks słownika i pliki tematyczne (klasyfikacja, struktury, assembly_alcs, osie_uklady, podzial_obiektow), interpretacja, intent debug-classification, README cs1–cs4, similarity, assembly*, axes_levels, podzial_obiektow, trzy wykłady |
| `wiedza/klasyfikacja_cs.md` | 9 sekcji streszczenia w gicie |

## Uwagi
- Słownik CS (`handbook/glossary.md` + `glossary/*.md`) jest jedynym źródłem prawdy wartości enum; `system.md` każe przepisywać je dokładnie.
- `glossary/obudowa.md`, `obciazenia.md`, `obliczenia.md` są w `cs_statyka`, `polaczenia.md` i `spoiny.md` w `cs_polaczenia`, `geometria.md` w `cs_ifc`, `koszty.md`, `jeden_program.md`, `pipeline_moduly.md` w `cs_program`, żeby fragmenty się nie dublowały w profilu łączonym.
