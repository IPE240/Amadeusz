# Wiedza umiejętności „cs_statyka”

Ten plik jest dla ludzi: model go nie widzi.

- `model_obliczeniowy_cs.md`: streszczenie w gicie (model MES z IFC, static i magazyn wyników, obciążenia i obudowa,
  porównanie modeli, wyniki 3D).
- `zrodla\CS-cheak_structures\`: słownik obliczeń, obciążeń i obudowy, README modułów mes, static, loads, model_compare,
  results3d, wykłady użytkownika (MES, obudowa, dane analizy), plany łuków MES, obudowy i solwera, pomoc o obciążeniach,
  pułapki mes_model_obliczeniowy. Poza gitem.

Solverem jest RFEM albo Robot (umiejętności `rfem` i `cs_robot`); CS buduje model i czyta wyniki.
Podział repozytorium CS na umiejętności: `profile\cs_program\README.md`.
