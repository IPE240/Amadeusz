- Grubość środnika tw (IPE/HE): < 7 ±0,7; 7–10 ±1; 10–20 ±1,5; 20–40 ±2; 40–60 ±2,5. INP: < 7 +0,5/−1; 7–10 +0,7/−1,5; > 10 +1/−2.
  UNP/UPE: ≤ 10 ±0,5; > 10 ±0,7.
- Grubość pasa tf (IPE/HE): < 6,5 +1,5/−0,5; 6,5–10 +2/−1; 10–20 +2,5/−1,5; 20–30 +2,5/−2; 30–40 ±2,5; 40–60 ±3; ≥ 60 ±4. INP: ≤ 7 +1,5/−0,5;
  7–10 +2/−1; 10–20 +2,5/−1,5; > 20 +2,5/−2. UNP/UPE: h ≤ 140 −0,5; 140–300 −1; > 300 −1,5.
- Nierównoległość pasów k + k′ (IPE/HE): b ≤ 110: 1,5 mm; b > 110: 0,02·b (max 6,5). INP/UNP: b ≤ 100: 2 mm; > 100: 0,02·b (UNP 0,025·b).
  Wygięcie środnika f (IPE/HE): h ≤ 100 ±0,5; 100–200 ±1; 200–400 ±1,5. Niesymetria środnika e: t < 40: b ≤ 110: 2,5; 110–325: 3,5; > 325: 5 mm;
  t ≥ 40: b ≤ 325: 5; > 325: 8 mm. INP: b ≤ 100: 2, > 100: 3 mm.
- Prostość q1, q2 (IPE/HE, INP): h ≤ 180: 0,003·L; 180–360: 0,0015·L; > 360: 0,001·L. UNP/UPE: q1: h ≤ 150: 0,003·L; 150–300: 0,002·L; > 300: 0,0015·L;
  q2: h ≤ 150: 0,005·L; 150–300: 0,003·L; > 300: 0,002·L.
- Masa: IPE/HE i INP ±4 %; UNP/UPE: h ≤ 125 ±6 %, > 125 ±4 %; TPH: tf 4–7: −8 %, tf > 7: −6 %. Tolerancje wykonania i montażu: SIA 263/1 pkt 10.

# Wzory geometryczne SZS C5 s. 114–115: trójkąty, trapez, koło, półkole, elipsa, wycinek i odcinek koła, parabola

- Trójkąt prostokątny: a = c·sin α = c·cos β = b·tan α; c = a/sin α = √(a² + b²); sin α = a/c, cos α = b/c, tan α = a/b; pole A = a·h/2,
  środek ciężkości w h/3; m·n = p². Trójkąt dowolny: a = b·sin α/sin β; c = √(a² + b² − 2ab·cos γ); cos α = (b² + c² − a²)/(2bc); γ = 180° − (α + β).
  Nachylenie: tan α = h/l; nachylenie w % = 100·h/l.
- Równoległobok: A = a·h, zs = h/2, Iy = a·h³/12. Trapez: A = (a + b)·h/2, zs = h/3·(a + 2b)/(a + b), Iy = h³/36·(a² + 4ab + b²)/(a + b).
- Koło: A = π·d²/4 ≈ 0,7854·d², U = π·d, Iy = π·d⁴/64. Półkole: A = π·r²/2, ys = 4r/(3π), Iy = r⁴(π/8 − 8/(9π)) ≈ 0,1098·r⁴, Iz = π·r⁴/8.
  Elipsa: A = π·a·b, U ≈ π·(a + b)·(1 + …) ≈ a + b + 3√(a² + b²)… (przybliżenie C5), Iy = π·a·b³/4.
- Wycinek koła (kąt α w radianach, cięciwa c = 2r·sin(α/2)): A = α·r²/2, ys = (2/3)·r·c/(α·r) … (położenie środka ciężkości 2rc/(3b), b = α·r),
  Iy = r⁴/8·(α − sin α), Iz = r⁴/8·(α + sin α). Odcinek koła: A = r²/2·(α − sin α), h = r·(1 − cos(α/2)).
  Odcinek paraboli: A = 2bh/3, zs = 3h/5, Iy = 8bh³/175, Iz = hb³/30.
